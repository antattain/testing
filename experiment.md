# Patent Attorney Workspace Design Specification

## Post-Analysis Workspace Layout
- **Claim Chart:** A visual representation of patent claims and their interactions.
- **Right-side Chat Panel:** An integrated chat for attorney-client communication.

## Interaction Patterns
- Users can access the claim chart from various sections of the workspace.
- Chat panel interactions should allow for quick replies and document sharing.

## Working Modes
1. **Review Mode:** Focused on analyzing claims.
2. **Collaboration Mode:** Emphasizes communication with clients.

## Visual Style Guidelines
- Use a clean and professional color palette.
- Font choices should enhance readability and be consistent across the workspace.
